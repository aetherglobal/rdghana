# Careers — Administrator Guide

Vacancies on **/careers** are managed in the admin panel (`/admin`) under **Careers → Job Openings**. No code changes are needed.

## What appears on the website

A vacancy is listed publicly only when **all** of these are true:

- **Status** is **Open**
- its **Publication Date** has arrived (or is blank)
- its **Application Deadline** has not passed — it stays listed until the end of the deadline day, Ghana time
- it has a **Job Description PDF** attached

Draft, Closed and Archived vacancies never appear on the site but remain in the admin. Saving a vacancy updates the site immediately; scheduled publication dates and expired deadlines take effect within an hour.

Order on the page: **Featured** vacancies first, then **Display Order** (lower numbers first), then newest publication date.

## Common tasks

| Task | Steps |
|---|---|
| **Create** | Job Openings → **Create New**. Enter the title, department, location, short description, deadline and application email. Leave Status as **Draft** while preparing. |
| **Attach the PDF** | In **Job Description PDF**, choose **Upload new** (or pick an existing PDF from the media library). Name the file as you want visitors to see it when downloading. |
| **Publish** | Set **Status** to **Open** and **Save**. To schedule, set a future **Publication Date** first. A vacancy cannot be opened without a PDF. |
| **Edit** | Open the vacancy, change any field (including replacing the PDF) and **Save**. |
| **Close** | Set **Status** to **Closed** and **Save**. It disappears from the site; the record stays. |
| **Archive** | Set **Status** to **Archived** for long-term records. Use the list filters/columns to find archived vacancies. |
| **Reopen** | Move the **Application Deadline** to a future date, set **Status** to **Open**, **Save**. (Opening with a past deadline is blocked with a message.) |
| **Feature** | Tick **Featured Position**. |
| **Reorder** | Set **Display Order** (e.g. 1, 2, 3). |

## Page-wide settings

**Careers → Careers Page** holds the **General Recruitment Email** (used by the “Email Your Application” button) and an optional **Hero Image** shown beside the page heading.

## Applications

“Apply Now” opens the visitor’s email client addressed to the vacancy’s **Application Email**, with the job title as the subject. The website does not collect or store CVs or applicant data.
